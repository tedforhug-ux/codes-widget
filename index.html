Codes widget

Browser extension for Chrome · Расширение для Chrome

English

Codes widget watches your Gmail inbox for one-time security codes from senders you choose (for example Namecheap, GitHub or Steam) and shows the code in a small card in the corner of the browser with a “Copy” button.

  • Read-only access to Gmail (gmail.readonly).
  • All processing happens locally in your browser. There is no server.
  • The extension is shared privately with friends and is not distributed publicly.

Русский

Codes widget следит за почтой Gmail и, когда приходит письмо с кодом подтверждения от выбранных отправителей (например Namecheap, GitHub, Steam), показывает код в углу браузера с кнопкой «Копировать».

  • Доступ к Gmail только на чтение (gmail.readonly).
  • Вся обработка происходит в браузере, сервера нет.
  • Расширение распространяется только среди друзей.
